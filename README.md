# Bank-s-Account-Payables-AI-Agent-System-with-Advanced-AI-Governance
Custodian is a governed multi-agent finance-ops platform: AI agents read invoices, score them for fraud/risk, route approvals, and auto-pay the safe ones. Six real governance layers wrap the agent runtime — Identity, Data, Model, Policy, Agent Runtime, and Operations — so every agent action is auditable and provable after the fact.
